Code abgelehnt? Lies die Meldung

Die Bestellseite ist auf Französisch. „Code inconnu“: Ein Buchstabe fehlt, kopiere die Zeile oben erneut. „Cette offre est terminée“: Die Frist ist vorbei. „Une erreur est survenue“: Die Verbindung ist gescheitert, versuche es später. Ein abgelehnter Code stoppt den Kauf: Es wird nichts abgebucht, und das Spiel wird nie unbemerkt zum vollen Preis verkauft.

Wo die Promo nicht gilt

Artikel im eingebauten Shop behalten ihren Preis: Kartenrücken, Tischtücher, Jetonpakete. Auch Google Play ist nicht betroffen. Im Browser und unter Linux ist Tarot gratis: Es gibt nichts einzulösen.

Was das Spiel nach dem Rabatt bietet

Der Preis ist nicht die einzige Wirkung. Das Konto erhält 200.000 Jetons, wählt vier Kartenrücken und zwei Tischtücher unter denen, die ihm fehlen, und nimmt zwölf Monate lang kostenlos an Tarot-Turnieren teil.

Lässt sich ein Code kombinieren oder später nutzen?

Nein. Pro Bestellung gilt nur ein Code, und zwar beim Kauf, ohne Rückwirkung. Der Preis steht fest, sobald die Bestellung angelegt ist: Wer vor Mitternacht beginnt, behält den Betrag der Promo, solange die Zahlungsseite gültig bleibt. Das Tarot-Spiel selbst bleibt dauerhaft verfügbar.
