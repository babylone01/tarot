Télécharger le jeu de tarot pour Linux

Tarot Gothique 2026 est disponible gratuitement sur Linux : le même jeu de tarot que sur Android, en solo contre l’intelligence artificielle ou en ligne contre d’autres joueurs, avec les règles du tarot français à 3, 4 et 5 joueurs.

Télécharger Tarot Gothique 2026 pour Linux (.tar.gz, 80 Mo)

Contenu de l’archive

  • Version 1.0.11 du jeu, pour PC Linux 64 bits (x86_64).
  • Un dossier tarot-gothique prêt à lancer : aucune installation système, aucun droit administrateur pour le jeu lui-même.

Configuration requise

Système

  • Distribution Linux 64 bits récente : Ubuntu, Debian, Linux Mint, Fedora, Arch, Manjaro…
  • Bureau graphique (X11 ou Wayland) avec accélération graphique.
  • Connexion Internet pour le jeu en ligne ; le mode solo fonctionne hors ligne.

Bibliothèques nécessaires

Le jeu utilise GTK 3 pour sa fenêtre et GStreamer pour la musique et les sons. Elles sont déjà présentes sur la plupart des bureaux ; sinon, installez-les avec la commande de votre distribution ci-dessous.

Installation du jeu de tarot sur Linux

Ubuntu, Debian et Linux Mint

1. Installer les bibliothèques

sudo apt install libgtk-3-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good

2. Décompresser et lancer le jeu

tar xzf tarot-gothique-1.0.11-linux-x64.tar.gz
cd tarot-gothique
./tarot

Fedora

sudo dnf install gtk3 gstreamer1-plugins-base gstreamer1-plugins-good

Puis décompressez et lancez le jeu comme ci-dessus.

Arch Linux et Manjaro

sudo pacman -S gtk3 gst-plugins-base gst-plugins-good

Puis décompressez et lancez le jeu comme ci-dessus.

Jouer au tarot sur Linux : solo et en ligne

Le mode solo est gratuit et se joue sans compte, contre une IA qui apprend votre façon de jouer. Le jeu en ligne demande un compte : vous retrouvez alors vos jetons et vos amis, que vous jouiez sur Linux, sur Android ou directement dans le navigateur.

Pour découvrir les règles avant votre première partie : règles du jeu de tarot.

Questions fréquentes sur la version Linux

Le jeu de tarot est-il gratuit sur Linux ?

Oui : le téléchargement et le jeu sont gratuits. Des jetons et des éléments de personnalisation sont proposés en achats intégrés facultatifs pour le jeu en ligne.

La musique ou les sons ne marchent pas, que faire ?

Installez les paquets GStreamer « plugins-base » et « plugins-good » de votre distribution (voir ci-dessus), puis relancez le jeu.

Comment mettre à jour le jeu ?

Téléchargez la nouvelle archive sur cette page et remplacez l’ancien dossier tarot-gothique. Vos parties en ligne et vos jetons sont liés à votre compte, pas au dossier.

Existe-t-il une version Windows ?

Oui : la version Windows (Windows 10 et 11) est disponible pour 9,90 €, en paiement unique. Le jeu se joue aussi gratuitement dans le navigateur.
