Download the tarot card game for Linux

Tarot Gothique 2026 is available for free on Linux: the same tarot card game as on Android, solo against the AI or online against other players, using the rules of French tarot for 3, 4 and 5 players.

Download Tarot Gothique 2026 for Linux (.tar.gz, 80 MB)

What the archive contains

  • Version 1.0.9 of the game, for 64-bit Linux PCs (x86_64).
  • A ready-to-run tarot-gothique folder: no system install and no administrator rights needed for the game itself.

System requirements

System

  • A recent 64-bit Linux distribution: Ubuntu, Debian, Linux Mint, Fedora, Arch, Manjaro…
  • A graphical desktop (X11 or Wayland) with hardware acceleration.
  • An Internet connection for online play; solo mode works offline.

Required libraries

The game uses GTK 3 for its window and GStreamer for music and sound. Most desktops already have them; if not, install them with your distribution’s command below.

Installing the tarot game on Linux

Ubuntu, Debian and Linux Mint

1. Install the libraries

sudo apt install libgtk-3-0 gstreamer1.0-plugins-base gstreamer1.0-plugins-good

2. Extract and start the game

tar xzf tarot-gothique-1.0.9-linux-x64.tar.gz
cd tarot-gothique
./tarot

Fedora

sudo dnf install gtk3 gstreamer1-plugins-base gstreamer1-plugins-good

Then extract and start the game as above.

Arch Linux and Manjaro

sudo pacman -S gtk3 gst-plugins-base gst-plugins-good

Then extract and start the game as above.

Playing tarot on Linux: solo and online

Solo mode is free and needs no account: you play against an AI that learns how you play. Online play needs an account, so you keep your tokens and friends whether you play on Linux, on Android or right in your web browser.

To learn the rules before your first game: tarot game rules.

Linux version: frequently asked questions

Is the tarot game free on Linux?

Yes: downloading and playing are free. Tokens and cosmetic items are offered as optional in-app purchases for online play.

There is no music or sound. What should I do?

Install your distribution’s GStreamer “plugins-base” and “plugins-good” packages (see above), then restart the game.

How do I update the game?

Download the new archive from this page and replace the old tarot-gothique folder. Your online games and tokens belong to your account, not to the folder.

Is there a Windows version?

A Windows version is in the works. Meanwhile, you can play on Android and in your web browser.
